# UI Automation (Cypress/Katalon)

File sample_ui_test.cy.js adalah contoh script E2E berbasis Cypress.

## Menjalankan Cypress (opsional)
1. npm install cypress --save-dev
2. npx cypress open
3. Letakkan sample_ui_test.cy.js ke folder cypress/e2e
4. Jalankan test dan rekam hasil untuk video

Jika tim memilih Katalon/Selenium, ganti folder ini dengan project/script yang setara.
