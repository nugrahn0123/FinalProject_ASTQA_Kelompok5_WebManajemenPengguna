# Test Scripts and Automation

Folder ini berisi artefak script otomatisasi pengujian untuk ASTQA.

## Struktur
- unit_and_integration_tests: referensi test Laravel (PHPUnit)
- jmeter_or_postman_scripts: script untuk load/API test
- ui_automation_katalon_cypress: script UI automation E2E

## Cara Pakai Cepat
1. Jalankan unit+integration test:
   - php artisan test
2. Jalankan load test:
   - gunakan script sample di folder jmeter_or_postman_scripts
3. Jalankan UI automation:
   - gunakan script sample di folder ui_automation_katalon_cypress
